## Roomify

This project was created using the [JavaScript Mastery "Build and Deploy a Full-Stack AI App" tutorial](https://www.youtube.com/watch?v=JiwTGGGIhDs).
React Router is used for the framework. Puter provides the serverless worker, file storage, and AI models.
Code reviews were conducted by CodeRabbit.

The tutorial was followed until I ran out of free AI credits on Puter.
